### Investigating How Query Complexity and User Age Influence Perceived Speech Delay Naturalness in Robot Interaction
---
#### Contents of this repository
This repository is intended to provide supplementary data for the paper 'Investigating How Query Complexity and User Age Influence Perceived Speech Delay Naturalness in Robot Interaction.' 

The file **video.mp4** provides an example of the interactions performed in the study. 

Additionally, the file **complexity_labelled_questions.pdf** provides a list of the questions used for the study as well as the prerecorded response from the robot and the expected complexity of the question.

---
#### How to reference this repository
To reference the contents of this repository, please cite our paper: **'Investigating How Query Complexity and User Age Influence Perceived Speech Delay Naturalness in Robot Interaction'** published in ICSR 2026.
